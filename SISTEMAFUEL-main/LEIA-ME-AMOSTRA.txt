AMOSTRA DO FUEL JOBS

1. Extraia este ZIP.
2. Envie o CONTEÚDO da pasta SISTEMAFUEL-main ao seu repositório: index.html deve ficar na raiz do repositório.
3. Para visualizar localmente, abra index.html no navegador.
4. Para publicar como página, configure o GitHub Pages para a branch e a pasta raiz que contêm index.html.

O index.html é uma amostra estática do dashboard original, com dados fictícios.
Inclui visualização em tabela e Kanban, filtros e detalhes demonstrativos.
Login, gravação de dados e outras páginas precisam do servidor do sistema original.

README.md, sistemaquasepronto.zip e pluginsclaude.zip foram preservados integralmente.
Nenhum arquivo original foi alterado. Foram adicionados somente index.html e este guia.
